# Manage Dev Spaces

As an administrator, you can manage the dev spaces in your account.

From the Dev Space Management tool, you can:

-   See a list of the dev spaces in your account.
-   Use the *Search* field to filter the list by the ID, name, or type of the dev space.
-   Filter the list by the name of the user who created the dev space.
-   Use the *Last Used Date* field to filter the list to show all dev spaces used up to the selected date.
-   Download the content of your dev spaces. You can download up to two dev spaces at a time.
-   Delete dev spaces.
    -   You can delete individual dev spaces by clicking the ![](images/delete_43e033a.png) icon on the relevant row.
    -   You can delete several dev spaces at once by clicking *Delete* at the top of the table.


**To access the tool:**

-   In your browser, enter the following URL: `https://<landscape-url>/workspace-manager-ui/admin/index.html`

-   **[Restart a Dev Space](restart-a-dev-space-1f54583.md "You can change the state of a dev space to Running.")**  
You can change the state of a dev space to *Running*.
