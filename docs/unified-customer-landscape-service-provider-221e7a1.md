# Unified Customer Landscape Service Provider

The Unified Customer Landscape service provider includes services and events from registered SAP S/4HANA Cloud systems in SAP BTP, as well as data products for SAP S/4HANA Cloud Private Edition. These resources can be used as data sources or for application development.

Within Unified Customer Landscape, you can explore two main types of resources:

-   Services and Events—see [Explore Services and Events in Unified Customer Landscape](explore-services-and-events-in-unified-customer-landscape-830adeb.md)
-   Data Products—see [Explore Data Products in Unified Customer Landscape](explore-data-products-in-unified-customer-landscape-7aa6cc6.md)
