# Full-Stack ABAP Application

Develop full-stack ABAP applications for modeling business objects using the ABAP Cloud development model. This dev space contains a comprehensive set of tools, including project templates, graphical modeling and visualization, service publishing, and UI development.

See [Develop a Full-Stack ABAP Application in SAP Business Application Studio](https://help.sap.com/docs/bas/developing-full-stack-abap-application-in-sap-business-application-studio-40adaba361e2469493d47bf9757e87c7/developing-full-stack-abap-application-in-sap-business-application-studio?version=Cloud).

The Full-Stack ABAP Application scenario contains the following predefined extensions:

-   **Basic Tools**

    Allows you to perform operations such as build and deployment of multitarget applications, while optimizing your web development workflow. The extension includes capabilities such as the Cloud Foundry CLI, a code editor, file management capabilities, split view and window management, preferences and settings.

-   **CDS Graphical Modeler**

    Allows you to design SAP core data service models in SAP Cloud Business Application development projects.

    The extension includes the CDS Editor, which provides capabilities for SAP business developers to visually design SAP CDS models. Models include artifacts, such as entities, types, unstructured types, enums, arrayed types, events, associations and compositions, and projects and services, which accelerate SAP Cloud Business Application development.

    See [Design CDS Models Using SAP Business Application Studio](https://help.sap.com/viewer/80d8499164f14d90bfd1cb11f961bb94/Cloud/en-US).

-   **SAP Fiori Tools**

    Allows you to simplify the development of SAP Fiori elements applications by providing extensions that can help you create applications, visualize navigation, automatically generate code, and more. The following extensions will be installed:

    -   Fiori elements Yeoman Generator

    -   SAPUI5 Adaptation Project Yeoman Generator

    -   Application Modeler

    -   Guided Development

    -   Service Modeler

    -   XML Annotation Language Server


    See [Getting Started with SAP Fiori tools](https://help.sap.com/docs/bas/developing-sap-fiori-app-in-sap-business-application-studio/getting-started-with-sap-fiori-tools).

-   **Full-Stack ABAP Tools**

    Allows you to develop full-stack applications for modeling business objects using the ABAP Cloud development model, supporting remote ABAP modeling and local UI development. This extension includes capabilities such as project creation, opening remote ABAP CSN files, graphical modeling and visualization, ABAP artifact generation, service publication, and UI creation for ABAP services.

-   **Service Center**

    Allows you to explore services from various providers, use the services as data sources in your application, and trigger application development.
