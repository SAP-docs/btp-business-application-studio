# Open a Support Ticket

If you did not find an answer in the troubleshooting section, you can report an incident or error through the SAP Support Portal.

> ### Caution:  
> The dev space owner is responsible for any content developed in SAP Business Application Studio or any packages installed by the user.
> 
> Support for open-source samples and tools follows the license agreement and documentation of the open-source.

You can report an incident or error through SAP for Me.

1.  Open [SAP for Me](https://help.sap.com/docs/link-disclaimer?site=https%3A%2F%2Fme.sap.com%2Fhome) and log on.

2.  Open the *Services & Support* dashboard.

3.  *Optional*: You can use the *Knowledge Search* tab for existing solutions in:

    -   SAP Notes & Knowledge Base Articles \(KBAs\)

    -   SAP Community

    -   SAP Support Portal

    -   Product Documentation
