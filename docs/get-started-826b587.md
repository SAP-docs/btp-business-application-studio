# Get Started

This section provides an overview of the essential steps to effectively begin working in SAP Business Application Studio.

> ### Note:  
> If you are working in a trial account, follow the procedure in [Getting Started with a Trial Account](https://help.sap.com/docs/bas/sap-business-application-studio/getting-started-with-trial-account?version=Cloud).



## Prerequisites

-   Make sure you have created a global account in the SAP BTP cockpit. See [Getting a Global Account](https://help.sap.com/docs/btp/sap-business-technology-platform/getting-global-account).
-   Make sure your administrator has set up SAP Business Application Studio in your subaccount. See [Set Up SAP Business Application Studio](set-up-sap-business-application-studio-19611dd.md).



## Procedure

1.  **Select a Dev Space**: Open SAP Business Application Studio and choose an appropriate dev space based on your project requirements. See [Create a Dev Space](https://help.sap.com/docs/bas/sap-business-application-studio/working-in-dev-space-manager?version=Cloud#create-a-dev-space).
2.  **Create a Project**: Start a new project within the selected dev space. See [Create a Project](https://help.sap.com/docs/bas/sap-business-application-studio/create-project).
3.  **Test and Run**: Utilize built-in tools to test and run your project, ensuring functionality and making necessary adjustments. See [Test and Run](https://help.sap.com/docs/bas/sap-business-application-studio/test-and-run).
4.  **Build and Deploy**: Build and deploy your application to transition from development to production readiness. See [Build and Deploy](https://help.sap.com/docs/bas/sap-business-application-studio/build-and-deploy).
